小提示

提个醒现在接管 聊天回复、模型异常中断、计划任务和巡检完成四类提醒。为避免聊天回复双弹，可以把 Hana 设置里「聊天回复完成」那条原版通知设为「从不」。计划任务和巡检都会留一点时间识别 Hana 原版通知；检测到同一活动已有原版通知时，提个醒就跳过补弹。

按助手个性化

每个助手可以配不同的音效、通知风格和提醒时机。风格只改变标题语气和正文包装，正文永远显示助手原话，不改写不生成；音效用你放进来的音频文件；提醒时机只影响「聊天回复完成」，选「跟随全局」就用上面全局档位。
右边两列是 Code 窗口专用的文案和音效。Code 窗口弹出的提醒标题前面会带一个「〔Code〕」记号，一眼就能认出它是代码窗口那边收工了。两列默认都是「跟随普通模式」，不碰就和左边完全一样；想分开配就在这两列里选。
🎁 方言风格和「学我说话」这一版暂时用不了：它们原本靠表情包联动挂载，表情包换形态后路径对不上，所以风格列表里暂时不会出现这两类，以后修。其他风格照常。
默认在应用自己的数据目录里，想自己挑地方放音效（比如放别的盘），点「选择文件夹…」或者手动填路径都行，留空恢复默认。填好保存后，把音频文件放进去，点「刷新音效」就能选。
