# 提个醒 🔔

> 给 Hana 的桌面通知加一只小喇叭：伙伴回复完成的时候，按你的设置弹一条 Windows 通知。

当前版本：`0.0.16`

当前版本最近一次自动测试结果（2026-10-10）：全量自动测试 390/390 通过。

## ⚠️ 先看这里

- **只支持 Windows 10 / 11。** 提醒走的是 Windows 自带的桌面通知，其他系统不保证能正常工作。
- **提个醒会自己拉一个 PowerShell 子进程去弹窗。** 这么做是为了保住伙伴头像、专属音效和通知来源名。脚本没有给出提交确认时，才退回 Hana 自己的通知通道。
- **弹窗音效要你自己准备音频文件**，这一版不自带任何音效，也不会替换你的系统音效。
- **「文案润色」默认关闭。** 打开以后，通知需要的那点短摘要会发给你选择的模型；模型失败或超时会自动退回本地规则版，不会让通知悄悄消失。
- **只提醒你真的在聊的窗口。** 后台自己跑起来的会话（定时调度、插件自己的日常动作那类）不会弹你。
- 通知「提交成功」只说明 Windows 接受了这条请求，不代表横幅一定显示——免打扰、专注模式、系统通知设置都可能把它拦住。

## 这是干什么的？

你切到别的窗口去做事，Hana 在后台回完了，你并不知道。原版 Hana 也有一条提示，但只有简单一句，我看不出是哪个窗口完成、是谁回的。

提个醒想解决的是这件事：不只弹一条通知，而是让每条通知都告诉你**哪个窗口、哪位伙伴、说了什么**。多开几个窗口同时聊的时候，一眼就知道该回哪一边；再给不同伙伴配上不同的音效和文案风格，听一耳朵就知道是谁在叫你。

## 它能做什么

- 💬 **回复完成提醒**
  - 四个档位：总是提醒 / 当前聊天没在看时提醒 / Hana 不在前台时提醒 / 关闭。
  - 同一个窗口 30 秒内的连续回复合并成一条，窗口结束后补一条汇总；不同窗口互不合并。
  - 只在最终回复完成时提醒，工具调用过程中的中间回合不会每一步都弹；你自己打断后重发（比如改个错字）也不把旧回合当成完成回复。
  - 对话框还有后台任务在跑的时候先等一等，不在中间过程插一条。
- 🪟 **多个窗口分得清**
  - 通知上尽量带伙伴头像和会话标题，谁、哪个窗口一目了然。
  - 标题由宿主给会话起名；刚开的新窗口第一条通知可能还没有标题，过一会儿就正常了。
- 🎨 **按伙伴个性化**
  - 每位伙伴可以单独选通知风格和音效，风格与音效自由组合。
  - 内置风格：跟随默认、简洁高效、活泼可爱、温柔贴心、闺蜜俏皮、古风书简、大厂黑话，外加一组整活风格（摩斯电码、系统故障、锟斤拷）。
  - 另有一组方言风格和「学我说话」，原本是跟表情包联动挂上去的，**当前版本暂时用不了**（见下面的「已知边界」）。
  - 规则版只包装标题、正文照实显示，不改写伙伴的原话。
- 🔔 **自定义音效**
  - 支持 `.wav`、`.mp3`、`.m4a`、`.aac`。
  - 音效文件夹自己选：点「选择文件夹…」叫出 Windows 原生选择框，或手动填绝对路径；放好音频后点「刷新音效」，就能按伙伴分配并试听。留空就用默认目录。
  - 也可以选系统默认音效或静音；这些设置只影响提个醒自己的通知。
- ⏱️ **弹窗停留时间**
  - 「系统默认」或「停留久一些」两档，这是 Windows 原生通知给的选项，不能精确填任意秒数。
- 🌙 **静默时段**
  - 设一段时间全部安静，支持跨午夜，例如 `22:00 至 08:00`。
- 🙈 **不想看到的伙伴可以收起来**
  - 设置页可以把某几位伙伴收进隐藏名单，ta 不再出现在设置列表和测试通知里。**这只是收起显示，不会停掉提醒**；要彻底不提醒，把 ta 的提醒档位改成「从不提醒」。
- ✍️ **可选的文案润色**
  - 对默认、简洁、活泼、温柔、闺蜜俏皮、古风书简、大厂黑话这类语气风格生效；整活风格不会调用模型。
  - 模型来源：交给 Hana 用默认模型处理（零配置，不保证逐条跟随某位伙伴），或者从 Hana 已配置的模型里挑一个。**自定义 API 这一版用不了**：应用还没申请联网授权，填了也发不出去。
  - 设置页有「测试一下」，不用对着一堆配置盲猜。开启后通常会多等一会儿，模型失败自动退回规则版。
- 🧪 **发一条测试通知**
  - 按你当前的配置走一遍真实弹窗链路，换音效、换风格之后可以先看效果。
- 🔎 **外部通知入口**
  - 别的应用或脚本也可以通过提个醒的接口弹一条通知，带上自己想要的标题、正文和音效。

## 怎么开始

1. 从 Release 下载这一版的压缩包。提个醒是 Hana v2 应用，装的是 `apps` 目录，不是 `plugins`：

   ```text
   <HANA_HOME>\apps\tigexing-app\
   ```

   压缩包里是直接的文件（没有外层文件夹），所以在 `apps` 下面先建好 `tigexing-app` 这个文件夹，再把解压出来的东西放进去。默认的 `HANA_HOME` 是 `%USERPROFILE%\.hanako`；在 Hana 里改过数据目录的话，换成你自己设的位置。文件夹名要和 `manifest.json` 里的 `id` 一致，装好后应该能看见 `apps\tigexing-app\manifest.json` 这个文件。

2. 重启 Hana，或者去扩展页「已安装」里点「重新加载」。
3. 它要是出现在「待批准」里，先批准；再去「设置 → 安全 → 应用能力」，把提个醒的权限打开（显示通知、启动外部程序、读取伙伴与资源、读取会话、读取模型与调用模型这几项）。通知和弹窗脚本都要靠这些权限，没开的话提醒会退化成一条干巴巴的系统通知，或者干脆不弹。
4. 打开「提个醒」页面，按需要调档位、停留时间、静默时段、每位伙伴的风格和音效。

默认配置就能用：回复完成时会提醒你。默认档是「焦点不在该聊天时」，但宿主的聊天焦点没法可靠确认，这种情况下提个醒会保守提醒，不会替你压掉通知；想完全不打扰就选「从不提醒」，或者设一个静默时段。

## 从插件版换过来

提个醒以前是一个 Hana 插件（现在不再更新了），这一版是它的应用形态。

**配置不会自动搬过来。** 应用不读插件版的数据目录，音效文件夹、每位伙伴的风格与音效、提醒档位、隐藏名单、静默时段，都要在新版页面里重新设一遍（默认配置本身能直接用，不设也能跑）。旧插件的文件不会被改动，也不会被删掉。

两版不要同时开着，否则同一件事会弹两次通知。核对好设置之后，再去扩展页把插件版停用。

## 卸载

在 Hana 的扩展页「已安装」里卸载，或者直接删掉 `<HANA_HOME>\apps\tigexing-app`。

卸载不会动你的设置和音效。想连数据一起清掉，先关掉 Hana，再删除：

```text
<HANA_HOME>\app-data\tigexing-app\
```

## 隐私

- 规则版通知全部在本机处理，不联网，也不把回复内容传到任何外部服务。
- 打开「文案润色」后，只会把生成通知需要的伙伴名、通知类型、短摘要和所选风格交给模型；完整聊天记录不会因为这项功能自动发送。
- 选自定义 API 时，地址和 Key 只在你主动配置并使用对应功能时才生效；Windows 下 Key 优先用系统 DPAPI 加密保存，系统加密不可用时页面会告诉你真实存储状态。
- 「检查更新」只在你主动点击时访问 GitHub。
- 设置、音效分配都保存在本机 `<HANA_HOME>\app-data\tigexing-app\`，不会打包进发布包。
- 提个醒不会修改任何伙伴的身份或性格文件。

## 兼容性

- Windows 10 / 11。
- HanaAgent `0.1059.0` 及以上（见 `manifest.json` 的 `minAppVersion`）。
- 不需要 Python、C# helper 或别的额外运行时；弹窗只用系统自带 PowerShell。
- 文案润色需要可用的文本模型配置；不配也能用，只是走规则版文案。

## 已知边界

这一版是从插件搬过来的，有几处还没接完，如实写在这里，不假装已经全好：

- **计划任务和巡检完成的接管还没做。** 设置页里这两块的开关和档位目前**不生效**，也不会补弹通知。**请保持 Hana 设置里「计划任务完成」「巡检完成」这两项原版通知开着**，关了就没人提醒你了。
- **断联（异常回合）提醒还没接上。** 相关代码已经拷过来了，判定和弹窗没接，设置页那个开关目前也不生效。
- **「焦点不在该聊天时」可能也会在你正看着的窗口弹。** 宿主给页面的是「当前选中会话」，不是后台可用的实时可见状态；没有可靠证据的时候，提个醒选择保守提醒而不是替你压掉。「焦点不在 HanaAgent 时」那一档是 **Hana 在前台就不提醒、切到别的应用时才提醒**，靠前台程序名判断，查询失败时仍可能提醒；它不是万无一失的免打扰开关，真要完全安静，请用「从不提醒」。
- **检查更新和反馈还在适配。** 这两个功能要走应用自己的出网白名单，目前还没接上，页面上的入口暂时用不了。
- **自定义 API 档还用不了**：应用还没申请联网授权，润色只能走「交给 Hana 处理」或「从 Hana 已配置的模型里挑」两种，自定义地址填了也发不出去。
- **方言风格和「学我说话」暂时用不了，等修。** 这两个风格原本是靠表情包联动挂上来的，表情包换了形态之后路径对不上，这一版不会出现这两个选项，其他风格照常。以后会把这条联动接回来，接好之前不硬凑一个半吊子的方言。
- **通知标题依赖宿主给会话起名。** 新建窗口的第一条通知可能来不及带上标题。
- **头像和音效能不能被弹窗脚本读到**，取决于你对应用资源权限的授权；读不到就退回应用图标和系统音效，不会因此不弹。

## 开发

在源码仓库目录跑自动测试（安装包不含测试文件，跑测试请用仓库）：

```powershell
node --test
```

检查全部 JavaScript 文件：

```powershell
Get-ChildItem -Recurse -Filter *.js | ForEach-Object { node --check $_.FullName }
```

宿主静态校验用 Hana 自带的 `scripts/validate-app.mjs`，必须读取非空结构化结果，不能只看退出码。测试细节见 [TESTING.md](TESTING.md)。
