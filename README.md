# 提个醒 🔔

> 给 Hana 的桌面通知换上专属语气和提示音：多开几个窗口，也能一眼认出是哪位伙伴回了。

当前版本：`0.0.21`

本轮全量自动测试：411/411 通过。包校验见对应版本发布说明。

## ⚠️ 先看这里

- **只支持 Windows 10 / 11。** 通知使用 Windows 自带的桌面通知，免打扰、专注模式或系统通知设置都可能拦住横幅。
- **弹窗音效要自己准备。** 这一版不附带音效文件，也不会替换你的系统音效。
- **提个醒会启动系统自带的 PowerShell 子进程来显示通知。** 这样才能带上伙伴头像、专属音效和通知来源名；需要在 Hana 的应用能力里允许「启动外部程序」。
- **「文案润色」默认关闭。** 打开后，生成通知所需的短摘要会交给你选的模型；完整聊天记录不会因为这项功能自动发送。模型失败或超时会退回本地规则版。
- **只提醒正在进行的聊天。** 定时调度或应用后台自己跑起来的会话，不会冒充成你正在聊的窗口来打扰你。

## 这是干什么的？

你切到别的窗口做事，Hana 在后台回完了，原版提示却只有一句简单的「回复完成」，看不出是哪位伙伴、哪个窗口。

我想让这条通知更像伙伴本人：除了告诉你**谁回了、哪个会话完成了、说了什么**，还可以给每位伙伴单独配一套文案风格和提示音。比如我给小花配了个「呀哈哈」音效，通知一响就知道她回来了，莫名喜感哈哈哈。

## 它能做什么

- 🎭 **给每位伙伴挑一套通知风格**
  - 内置跟随默认、简洁高效、活泼可爱、温柔贴心、闺蜜俏皮、古风书简、大厂黑话，还有摩斯电码、系统故障、锟斤拷等整活风格。
  - 每位伙伴可以单独选择风格，互不影响。规则版只包装通知标题，正文照实显示，不改写伙伴的原话。
  - 还可以开启「文案润色」，让模型按选定语气整理通知文案；设置页有「测试一下」，不用对着配置盲猜。
- 🔔 **按伙伴配专属音效**
  - 支持 `.wav`、`.mp3`、`.m4a`、`.aac`。
  - 选一个音效文件夹，放入自己的音频，点「刷新音效」就能分配给伙伴并试听；也可以用系统默认音效或静音。
- 💬 **回复完成提醒**
  - 可以选总是提醒、当前聊天没在看时提醒、Hana 不在前台时提醒，或关闭。
  - 同一聊天窗口 30 秒内连续回复会合并，窗口结束后补一条汇总；不同窗口互不合并。
  - 只在最终回复完成时提醒，工具调用过程中的中间回合不会每一步都弹；你打断后重发（比如改个错字）也不会把旧回合当成完成回复。
- 🗓️ **计划任务和巡检完成提醒**
  - 两类提醒分别设置提醒时机；计划任务还有独立的接管开关。
  - 如果提个醒识别到 Hana 已经为同一活动发过通知，就会跳过重复提醒。
- 🪟 **多个窗口分得清**
  - 通知会尽量带上伙伴头像和会话标题，多开窗口也不容易看串。
- 🌙 **静默时段**
  - 设置一段时间让所有通知安静下来，支持跨午夜，例如 `22:00 至 08:00`。
- ⏱️ **调整通知停留时间**
  - 可选「系统默认」或「停留久一些」。这是 Windows 原生通知提供的两档，不能精确填写任意秒数。
- 🙈 **收起不想配置的伙伴**
  - 可以把伙伴从设置列表和测试通知里隐藏起来；这只影响显示，不会停止提醒。要彻底不提醒，把 ta 的提醒档位改成「关闭」。
- 🧪 **先给自己发一条测试通知**
  - 按当前配置走一遍实际弹窗链路，换完风格或音效先听听、看看效果。

## 安装

1. 从 [GitHub Releases](https://github.com/moononnn/hanako-tigexing-app/releases) 下载应用版安装包。提个醒是 Hana v2 应用，放在 `apps` 目录，不是 `plugins`：

   ```text
   <HANA_HOME>\apps\tigexing-app\
   ```

   发布包里是直接的文件，没有外层文件夹。先在 `apps` 下面建好 `tigexing-app` 文件夹，再把压缩包里的文件解压进去。默认 `HANA_HOME` 是 `%USERPROFILE%\.hanako`；如果你在 Hana 里改过数据目录，就用自己的位置。文件夹名要和 `manifest.json` 里的 `id` 一致。

2. 去 Hana 扩展页「已安装」重新加载；如果需要重启 Hana，由你按平时的方式操作即可。
3. 如果提个醒出现在「待批准」里，先批准。然后打开「设置 → 安全 → 应用能力」，允许「显示通知」「启动外部程序」「读取伙伴与资源」「读取会话」「读取模型与调用模型」。没开齐时，通知可能退化成系统默认样式，头像、音效或文案润色也可能不可用。
4. 打开「提个醒」页面，按喜好调提醒档位、静默时段、伙伴风格和音效。

新安装默认就能用。由 `0.0.18` 升级时，新增的计划任务和巡检设置会按默认值初始化：计划任务接管开启，两类提醒设为「Hana 不在前台时提醒」。如果不想收到这两类提醒，升级后记得关掉计划任务接管，并把巡检设为「从不提醒」。聊天提醒的「焦点不在该聊天时」档位在宿主无法确认窗口焦点时会保守提醒；想完全安静，请选「关闭」或设置静默时段。

## 从插件版换过来

提个醒以前是 Hana 插件，现在应用版接上了 Hana v2 的应用机制。

**配置不会自动搬过来。** 应用版不读取插件版的数据目录，所以音效文件夹、伙伴风格与音效、提醒档位、隐藏名单和静默时段，都要在应用版页面重新设置。默认配置本身可以直接工作；插件版文件会原样留着，不会被改动或删除。

插件版和应用版不要同时启用，否则同一件事可能提醒两次。确认应用版设置妥当后，再到扩展页停用旧插件。

## 卸载

在 Hana 扩展页「已安装」中卸载提个醒，或删除 `<HANA_HOME>\apps\tigexing-app`。

卸载不会删除你的设置和音效。若还想清理这些个人数据，先关闭 Hana，再删除：

```text
<HANA_HOME>\app-data\tigexing-app\
```

## 隐私

- 规则版通知在本机处理，不需要联网，也不会把回复内容上传到外部服务。
- 开启「文案润色」后，只会把通知所需的伙伴名、通知类型、短摘要和所选风格交给模型；完整聊天记录不会因为这项功能自动发送。
- 设置、音效分配和自定义音频保存在本机 `<HANA_HOME>\app-data\tigexing-app\`，不会打包进发布安装包。
- 提个醒不会修改任何伙伴的身份或性格文件。

## 兼容性

- Windows 10 / 11。
- HanaAgent `0.1059.0` 及以上（见 `manifest.json` 的 `minAppVersion`）。
- 不需要 Python、C# helper 或其他额外运行时；弹窗使用系统自带 PowerShell。
- 文案润色需要可用的文本模型；不配置也能用，只是走规则版文案。

## 已知边界

这一版从插件迁移而来，以下能力还没接好或仍有条件限制：

- **计划任务和巡检完成提醒已在真实场景验证。** 原版通知去重依赖 Hana 的活动通知和活动会话路径能对应上；路径没匹配时，提个醒仍可能按档位补弹。
- **断联（异常回合）提醒尚未接入。** 相关设置目前也不生效。
- **「焦点不在该聊天时」不一定能准确判断你正在看的窗口。** 宿主没有提供可靠的实时可见状态，因此提个醒会保守提醒；「Hana 不在前台时提醒」依赖前台程序判断，查询失败时仍可能弹。
- **检查更新、应用内反馈和自定义 API 暂不可用。** 文案润色目前只能交给 Hana 处理，或从 Hana 已配置的模型中选择。
- **方言风格和「学我说话」暂不可用。** 它们原本依赖表情包插件联动，应用版的这条联动还没接回来；其他内置风格正常使用。
- 新建窗口的第一条通知可能还没有会话标题；头像或音效也受「读取伙伴与资源」权限影响。读不到时会退回应用图标和系统音效，不会因此取消通知。

## 开发

在源码仓库目录运行自动测试（安装包不含测试文件）：

```powershell
node --test
```

检查全部 JavaScript 文件：

```powershell
Get-ChildItem -Recurse -Filter *.js | ForEach-Object { node --check $_.FullName }
```

宿主静态校验使用 Hana 自带的 `scripts/validate-app.mjs`，需要检查非空结构化结果，不能只看退出码。测试细节见[源码仓库中的 TESTING.md](https://github.com/moononnn/hanako-tigexing-app/blob/main/TESTING.md)。
